# Build Prompt: P3-C03 — Model A ("direct")

**In plain words:** this builds the first of the two practice models that are
really learned: a small neural network that looks at the current state and the
push and predicts two things for each quantity — how it will change, and how
wrong it expects to be. It learns from the shared homework the harness hands
every model, in a way that does not let a stubbornly uncertain guess drown out
the fit (β-NLL). Before it learns anything, its learning arithmetic is checked
once against brute-force numbers. It can predict many runs at once, with
exactly the same numbers as predicting them one by one. And a build-time check
asks, once and without ever looking at the comparison between the two models,
whether 50,000 training examples are enough or 100,000 are needed.

## Spec Excerpt (models ADR-M1, ADR-M3)
- Input: `(state / ctx.scale, action / half-width of ctx.training_action_interval)`; output per dimension `(Δmean, log σ)`; `mean = state + Δmean`, `spread = exp(log σ)` (raw state units; the spec names no output scaling — recorded as A20).
- Shared architecture: 2 hidden layers × 64, tanh; `W ~ U(−1/√fan_in, 1/√fan_in)`, biases 0, from `seeds.rng("weights")`; epoch shuffles from `seeds.rng("shuffle", str(epoch))`.
- β-NLL: `w = σ^(2β)` with β = 0.5 computed from the current forward pass and held constant; `L = w·[0.5·log 2π + s + r²/(2σ²)]` summed over dimensions, averaged over the batch; `∂L/∂μ = −w·r/σ²`, `∂L/∂s = w·(1 − r²/σ²)`, each divided by the batch size.
- Mini-batch 256, Adam (lr 1e-3, β 0.9/0.999, ε 1e-8), fixed 100 epochs, no early stopping. Gradient check once before training: 64 pairs of `gradcheck_index`, plain Gaussian NLL, tolerance 1e-5.
- Sufficiency: train at M and 2M; held-out error = mean over `heldout_pairs` of mean over dimensions of `((mean − y)/scale)²`; `err(M) ≤ 1.10 × err(2M)` (the tolerance is the recipe's `sufficiency_tolerance: 0.10`); outcomes "M = 50,000" or "M = 100,000" only; report the held-out error split by kick and non-kick pairs.
- `predict_batch` rows bit-identical to `predict` (TC-MU1-04), every n ∈ {1, 2, 7, 64, 200}.
