# Build Prompt: P3-C08 — The action-response check and the fourth fixture (`fx-action-blind`)

**In plain words:** a model is only a *simulator* if it uses its action input. This
chunk adds (1) a check the harness runs on **every** model: hold the starting state
fixed, give the model two different actions from the range it was trained on, and
see whether its answer changes by more than floating-point noise; a model whose
answer never changes for any probe is flagged **action-blind**; and (2) the fourth
broken test model, `fx-action-blind` — Model A (the very same trained network) with
the action thrown away before it predicts — so we can show the check catches exactly
that. As always the fixture is test equipment, never a finding (MU-4).

## The rule (MU-3, fixed before any model was built)
For at least one (start state, action pair) probe the two predictions must differ by
more than floating-point noise; a model that never distinguishes any pair fails
(= flagged action-blind). Pinned choices (backlog A26, owner-visible in REMEMBER):
- **Probes:** 16 start states drawn from the world's training box by the harness's own seeded stream (`rng_for("action-response", "states")`, the same for every model); three action levels — the low end, the middle and the high end of the trained interval (closed ends included) — giving three pairs per state (48 probes).
- **"More than floating-point noise":** a difference of more than `1e-9` of the world's own scale in any dimension of the mean *or* of the error bar (float64 noise is ~1e-16 relative; every real action effect is far larger).
- **Stateful models:** `reset()` before every single prediction, so memory cannot masquerade as action response.
- A non-finite prediction is an error, not "identical".
