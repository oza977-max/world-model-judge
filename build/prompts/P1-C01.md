## Deliverables

1. `pyproject.toml` — pinned dependency set (`numpy>=1.26,<2.0`,
   `matplotlib>=3.8,<4.0`; dev: `pytest`), src-layout, pytest config.
2. `requirements.lock` — resolved pin snapshot (`pip freeze`, cleaned
   of the local editable-install line).
3. `src/wmj/errors.py` — `WmjError`, the shared base every package's
   own exceptions subclass.
4. `src/wmj/harness/serialize.py` — `canonical_serialize`,
   `NonFiniteValueError(WmjError, ValueError)`. Sorted keys, UTF-8,
   `\n` newlines, no trailing whitespace, `.tolist()`/`.item()` for
   NumPy types, `json.dumps(..., sort_keys=True, allow_nan=False)` as
   the sole float-rendering call (cross-cutting ADR-002 rule 4).
5. `src/wmj/models/base.py` — `component_key(*parts)` (blake2b
   digest_size=8 → one big-endian int in a 1-tuple; rejects non-`str`
   and `:`-bearing parts via `SeedKeyError`), `SeedSource` (frozen
   dataclass: `run_seed`, `my_name`, `rng(*purpose)`,
   `rng_for(*parts)`) (cross-cutting ADR-002 rule 2, pinned
   construction).
6. `src/wmj/harness/thread_guard.py` — `ensure_single_threaded()`
   (sets the three `*_NUM_THREADS` env vars to `"1"`, must run before
   `import numpy` anywhere in the process) and
   `assert_single_threaded()` (raises `ThreadGuardError` if any is
   unset or wrong) (cross-cutting ADR-002 rule 1).

## Review Criteria

**Tier 1 (architecture, always-on):** Steve McConnell (*Code
Complete* — defensive programming, fail loudly, error messages name
what failed / what was expected / which gate caught it); Andrew Hunt
& David Thomas (*The Pragmatic Programmer* — DRY as knowledge, no
duplicated seed-derivation logic); Michael Keeling (*Design It!* — ADR
traceability, the code should match the ADR-002 pinned text exactly,
not an approximate reading of it).

**Tier 3 (stack, numerical Python):** Luciano Ramalho (*Fluent
Python* — dataclasses for value types, type hints as documentation);
Ernst Hairer, Syvert Nørsett & Gerhard Wanner (*Solving Ordinary
Differential Equations I*) and David Goldberg ("What Every Computer
Scientist Should Know About Floating-Point Arithmetic") — both loaded
for this chunk because ADR-002's determinism rules are grounded in
their work (non-associativity of float ops motivating single-thread;
reproducibility as an ordering discipline), even though this chunk's
own code does no numerical integration itself.

## Framework Reference

`numpy.random.SeedSequence`/`PCG64`/`Generator` construction chain
(NumPy's recommended modern-RNG API, replacing the legacy global
`numpy.random.*` functions this project bans outright); `hashlib.blake2b`
stdlib digest API; `json.dumps(..., sort_keys=True, allow_nan=False)`
stdlib behaviour (raises `ValueError` on non-finite floats when
`allow_nan=False`).
