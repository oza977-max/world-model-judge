# Build Prompt: P4-C05 — Error versus horizon, climatology agreement, trust horizons

**In plain words:** three honest answers about how far ahead a model can be believed. (1) *The
error curve*: for each region, how far off is the model's best guess after 1, 2, 3 … steps —
typically the middle (median) trial — drawn beside the world's own drift curve, which is the best
any model could do. (2) *Past the switch step* (where the world itself has drifted beyond a task's
tolerance, so exact-path claims are no longer fair) the judge asks a different question: does the
model's guess still look like the world's long-run behaviour for the *same* amount of energy? —
"climatology agreement". (3) *The trust horizon*: the last step up to which the model stayed within
the task's tolerance at every step, never beyond the switch step, reported in steps, in world time
and, where the world has a natural cycle, as a fraction of that cycle — always with the task and
region it belongs to. Failing even at step 1 is reported as 0, not hidden.

## Conventions pinned here (also backlog A34)
- **Distance.** `distance.py`: root-mean-square over quantities of the (already normalised) gap, scaled by the row's largest gap (no under/overflow); the same function `exceptions` uses for its chart arrays.
- **`error_vs_horizon`** per region (sorted names): `steps` = `0..H`; `median_error[0] = 0` (no forecast is made at step 0 — the shared origin); `median_error[s]` = median over the region's trials of `distance(predicted mean, outcome)` at step `s` (array index `s − 1`); `divergence_reference` = the region's curve; block-level `dt`.
- **Agreement window.** Steps `switch .. task.horizon` inclusive (the task's own horizon, A31); every region trial; the bin for each (trial, step) is the *measured* `invariant_bins` entry in that region's table. `agreement_mean_abs_z` = mean over trials, steps and quantities of `|pred_mean − bin_mean| / bin_sd`; `agrees` iff it is `≤ thresholds.agreement_threshold` (closed). No switch step → all three fields null.
- **Trust horizon.** Let `cap = switch_step` if there is one, else `task.horizon` (the world's `H` in the spec; identical in both built worlds — A31/A33). `steps` = the last `h ≤ cap` such that the median error at every step `1..h` is `≤ τ` (closed); 0 if step 1 already fails. `world_time = steps × dt`; `natural_units = "<steps·dt / L:.2f> cycles"` when the world has a natural cycle length `L`, else null.
- Module layout follows the spec: `distance.py`, `horizon.py` (error curve + trust), `climatology.py` (+ agreement); `regions.py` holds the shared region helpers (needed to avoid an import cycle).
