# Build Prompt: P3-C05 — The three broken test models (fixtures)

**In plain words:** three models that are broken on purpose, each by exactly one
thing, so the judge can be shown to catch exactly that thing: one that is right
but cocky (its error bars are four times too small), one that is rougher but
honest (its guess is jittered and its error bar widened by exactly the right
amount), and one that is excellent at home and catastrophic away (outside the
region it was trained on it just says "nothing changes"). Each is Model A
(bit-for-bit the same trained network) plus one corruption. They are labelled
as fixtures everywhere — detecting a failure we built in is a passing test, never
a discovery (MU-4).

## Chunk Summary
From `specs/implementation-guide.md` v2.0, P3-C05 and models ADR-M4: three
one-corruption wrappers around a bit-identical `direct` core built via the same

are P4/P6), TC-MU4-01 (code surface), TC-MU4-02 (inner net weight-identical to
`direct`), TC-MU1-04 (fixtures).

## Spec Excerpt (models ADR-M4)
| Fixture | Corruption |
|---|---|
| `fx-overconfident` | spread × 0.25, mean untouched |
| `fx-honest-rough` | mean + seeded noise (σ = 2 × the model's spread); spread ← `sqrt(base_spread² + noise_σ²)` exactly |
| `fx-brittle` | if state ∈ `ctx.training_state_box` **and** action ∈ `ctx.training_action_interval` (closed): Model A's prediction; otherwise mean = state itself, spread untouched |
The inner core is built by calling the `direct` construction with the content-addressed `"direct"` seed so it is bit-identical to the registered `direct`. Corruption parameters are constants in the spec, not tunables.

## Design notes (recorded as backlog A25)
- "Seeded noise" must be a pure function of the input row (a stateless model must batch bit-identically, TC-MU1-04), so the noise is hashed from the row's bytes and a seed-derived key (integer mixing; a sum of twelve uniforms for ≈ N(0,1) — no transcendental functions, so batch size cannot change a bit).
- One trained core is shared by `direct` and the fixtures (4× training would cost ≈ 2 minutes per world and prove nothing); a test compares it with an independently trained `direct`.
