# P2-C04 — Region labelling

## Scope

Per `specs/implementation-guide.md` line 42: "In/out labelling with
axis attribution, boundary determinism." Needs P2-C01 + P2-C02 (done).
Parallel with P2-C03.

**Spec:** `specs/worlds.md` ADR-W4 (closed boxes, in-region on the
boundary, the four-value `axis` convention), §5 (the canonical label
shape `{"region_name": <declared key>, "axis": "state"|"action"|
"both"|null}`); `specs/cross-cutting.md` ADR-004 (starts are drawn
*per declared region*, so the region a trial belongs to is known by
construction; `region_labels` is one entry per trial); judge §4
(`region_labels: [n_trials]`, the join key reporting and the
climatology lookup use to pick a curve).

**Tests:** TC-WD5-01 (boundary determinism: just inside / just
outside / exactly on the boundary), TC-WD5-02 (state inside the
training box but an action outside the trained interval is flagged on
the *action* axis, not silently in-region).

**Wiring row:** `harness.regions`, consumed by `wmj run` (P6-C01).

## Scope decisions

- **`region_name` is the region the start was drawn for, not
  re-derived from the state.** ADR-004's loop samples `starts[r]` per
  declared region and every declared region's name must appear in
  `region_labels` (TC-NF1-09). `region_name` is the join key into the
  divergence artefact's `regions` object and the climatology table; the
  *attribution* (`axis`) is what ADR-W4 computes. A trial drawn for
  `"training"` whose rollout uses an out-of-range action is therefore
  labelled `{"region_name": "training", "axis": "action"}` — still
  compared against the training curve (that is where it started), but
  flagged as out-of-region on the action axis, exactly TC-WD5-02's
  case. A trial drawn for an out-region is always outside the training
  box on at least one axis (the boxes are validated disjoint at
  import), so its axis is `"state"` or `"both"`, never `null`.
- **Closed intervals everywhere:** `low <= x <= high` on every state
  dimension of the training box and every action dimension of the
  trained interval. A value exactly on the edge is in-region
  (TC-WD5-01's determinism; this is the same `<=` discipline as
  P2-C01's `within_tolerance`).
- **Fail loudly on an undeclared region name** (McConnell): the label
  must name a key that exists in the world's declared regions; a typo
  would otherwise silently detach a trial from every downstream lookup.
