# Build Prompt: P3-C01 — MLP core

## Chunk Summary

The hand-rolled NumPy MLP that both unrigged models (Model A "direct",
Model B "ensemble") are built on (models ADR-M3). Delivers `wmj/models/mlp.py`:
weight construction, forward, backward, an Adam optimiser step, and a
**gradient-check hook** that validates the hand-rolled backprop against
finite differences. Per models §8's pre-TC discipline, the gradient
check is the MLP's *first* test — written and Red before backward exists.

This chunk builds the **core only** — the shared architecture and its
optimiser. The task-specific heads and losses (direct's NLL + variance
head, the ensemble members' mean-only training) arrive at P3-C03/P3-C04,
which consume this module (wiring matrix: `models.mlp` → `models.direct`,
`models.ensemble`).

## Deliverables

1. `src/wmj/models/mlp.py`:
   - `MLP(layer_sizes: Sequence[int], rng: np.random.Generator)` — builds
     weight matrices `W ~ U(-1/√fan_in, 1/√fan_in)` and zero biases per
     layer (ADR-M3). Tanh on every hidden layer; **linear output layer**
     (outputs are Δmean / logσ / mean — unbounded).
   - `forward(X) -> (output, cache)` — `X: float64[batch, in]`.
   - `backward(cache, d_output) -> list[(dW, db)]` — reverse-mode grads
     given the upstream gradient `d_output: float64[batch, out]`. Loss-agnostic:
     the task loss lives one layer up (P3-C03/C04).
   - `Adam(shapes, lr=1e-3, beta1=0.9, beta2=0.999, eps=1e-8)` with
     `step(params, grads)` — the pinned ADR-M3 hyperparameters.
   - `gradient_check(mlp, X, loss_and_grad, *, epsilon=1e-6, tolerance=1e-6)
     -> float` — max relative error between analytic backprop and central
     finite differences; raises `GradientCheckError` if it exceeds tolerance.
     `loss_and_grad(output) -> (scalar_loss, d_output)`.
   - `MLPArchitectureError`, `GradientCheckError` (subclass `WmjError`).
2. `tests/unit/models/test_mlp.py`.

## Spec Excerpt (models ADR-M3, shared architecture)

- 2 hidden layers × 64 units, tanh; hand-rolled NumPy forward/backward.
- Weight init: `W ~ U(-1/√fan_in, 1/√fan_in)`, biases 0, from a seeded `Generator`.
- Adam: lr 1e-3, β₁ 0.9, β₂ 0.999, **ε = 1e-8** (all pinned — two
  implementers picking different defaults would get bit-different weights
  under NF-1).
- Gradient check: **one full-batch pass, finite-difference to 1e-6
  relative, run once before any training** — validates the hand-rolled
  backprop. It is *not* the training loop (mini-batch, batch 32 — P3-C03/C04).
- Model A's NLL formula (for downstream context, not built here):
  `NLL = 0.5·log(2π) + logσ + (y−μ)²/(2σ²)`, summed over d, averaged over batch.

Cross-cutting: `wmj/models/*` may import only numpy/math/dataclasses/typing/
`__future__`/`wmj.errors`/`hashlib`/`wmj.models.*` (ADR-003, TC-NF6-07/08/09) —
so `mlp.py` imports numpy + `wmj.errors` only. Determinism (ADR-002): every
random draw comes from the passed `Generator`, never `np.random.*` globals.
MLP weights are **mutable** (Adam writes to them) — the read-only-array
discipline applies to `Prediction`/`WorldContext`/region boxes, not here.

## Framework Reference

- `numpy.random.Generator.uniform(low, high, size)` — the fan-in-scaled init draw.
- `np.tanh`; its derivative `1 - tanh(x)**2` computed from the cached activation.
- Central finite difference: `(f(x+ε) - f(x-ε)) / (2ε)`; relative error
  `|analytic - numeric| / max(1e-12, |analytic| + |numeric|)`.
- Adam: `m = β₁m + (1-β₁)g`, `v = β₂v + (1-β₂)g²`, bias-correct by
  `1-β^t`, update `θ -= lr·m̂/(√v̂ + ε)`.

## TDD Approach

**TDD-1 exempted: internal helper (MLP core), no user-facing surface — the
gradient-check finite-difference test is the chunk's first deliverable per
models §8's pre-TC discipline.**

Order:
1. **FIRST test (Red):** `test_gradient_check_passes_on_correct_backprop` —
   build a small MLP, run `gradient_check` with an MSE `loss_and_grad`,
   assert the returned max relative error is < 1e-6. Red before backward exists.
2. Implement `MLP.__init__`, `forward`, `backward`, `gradient_check` until Green.
3. Phantom-gate: `test_gradient_check_raises_when_backprop_is_wrong` — feed
   `gradient_check` a deliberately corrupted analytic gradient (or a broken
   MLP) and assert `GradientCheckError` — proving the check can fail (Beck/Fagan).
4. Determinism: `test_two_mlps_from_the_same_seed_are_weight_identical`.
5. Adam: `test_adam_step_reduces_a_convex_quadratic_loss`.
6. Init: `test_weights_are_fan_in_scaled_and_biases_zero`.
7. **Realistic-fixture variant (TDD-3, numerical domain — practitioner-named
   shape):** `test_gradient_check_holds_on_a_single_example_batch_and_wide_dynamic_range`
   — a batch of one row with large-magnitude inputs (the shape a happy-path
   multi-row moderate-magnitude batch would miss). Not one of the six
   catalogue domains; named per the practitioner-extension clause.
