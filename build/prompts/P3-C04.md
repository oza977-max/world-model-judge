# Build Prompt: P3-C04 — Model B ("ensemble") and the P3-C02 re-open

**In plain words:** the second practice model, built to be as accurate as Model A
but to get its error bar a completely different way: five copies of the same small
network, each started from a different random point and shown the examples in a
different order. Where the five copies disagree, the model is unsure; the size of
their disagreement (with a small standard correction for having only five) *is*
the error bar. Alongside it, the two simple baselines (persistence and linear)
get the two small flags the spec now requires so the harness knows which models
can safely predict many runs at once.

## Chunk Summary
From `specs/implementation-guide.md` v2.0, P3-C04 + the P3-C02 amendment
(design-review-010): K = 5 members on MSE, point = mean of member means, spread =
`sqrt(1 + 1/K) × std(member means, ddof=1)`, members' streams
`seeds.rng("member", str(k), "weights")` and `("member", str(k), "shuffle",
str(epoch))`, batch 256 over `training.train_pairs`, 64-pair MSE gradient check
per member, `ensemble.predict_batch` through `forward_invariant`; the build-time
M-sufficiency check for the ensemble (the rule already decided by Model A's
failure — reported, cannot change the outcome). P3-C02: `persistence.stateless =
True` + `predict_batch`; `linear.stateless = False`. Tests: TC-MU5-02, TC-MU5-03,
TC-MU1-04 (every registered stateless model), TC-MU5-05.

## Spec Excerpt (models ADR-M3, ADR-M1)
- Members: the same architecture minus the variance head (output = the state change only), MSE on the state change, identical training data, differing only in seeded initialisation and shuffling. Adam as Model A (with the recipe's cosine decay), fixed epochs, no early stopping.
- Point prediction: the arithmetic mean of the K member means. Spread: `sqrt(1 + 1/K) × std(member_means, ddof=1)` per dimension.
- `predict_batch` rows bit-identical to `predict` (TC-MU1-04); stateless models only.
- MSE units (unspecified in the spec — backlog A24): the network outputs the change in raw state units (as Model A); the loss is the mean over examples and dimensions of `((μ − Δ)/scale)²`, i.e. exactly the held-out error metric.
