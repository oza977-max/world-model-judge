## Scope decisions this chunk makes

- **worlds.md §8's own pendulum reference value is stale and is not
  used.** §8 states: "The pendulum reference value must be
  (re-)computed from the design-review-002-corrected EOM above (§4.2)
  before this case can be implemented — any value computed from the
  v1.1 formula's `2·m` coefficients is wrong and must not be reused."
  No recomputed value is recorded anywhere in the spec suite. This
  chunk computes one, the same way P1-C02 did for LV: an independent,
  plain-Python (no NumPy) RK4 implementation of the exact corrected
  equations in §4.2, run from state `(0.1, 0.1, 0.0, 0.0)`, `u=0`,
  `dt=0.002`. The chosen state is deliberately non-degenerate (Δ=θ1-θ2=0
  there, which zeroes the θ̈2 term and the sin(Δ) half of θ̈1, but θ̈1's
  remaining gravity term is non-zero — verified: θ̈1 ≈ -0.9794 rad/s²,
  not a fixed point). Energy conservation was checked as a sanity cross-
  check (not the reference itself): relative drift ~1e-13 over one
  step, consistent with RK4's expected local error at this step size.
- **TC-WD7-01/02 (byte-identical trajectories, negative RNG-mutation
  detection) are placed here rather than deferred**, since the
  pendulum world (unlike LV so far) is the first world where a rollout
  runs many more steps (5000-step horizon) and this is the natural
  point to prove determinism holds over a long rollout, not just one
  step.

## Deliverables

1. `src/wmj/worlds/pendulum.py` — the double pendulum world: `d=4`,
   `a=1`, `dt=0.002`, `scale=(π, π, 2π, 2π)`, `transition(state,
   action)` (impulse-then-integrate: `ω1 <- ω1 + u`, then one RK4
   step of the corrected EOM), `conserved(state)` (total mechanical
   energy E), `regions()`, `tasks()` (`dp-control` τ=0.05, `dp-planning`
   τ=0.30) — constants exactly per worlds.md §4.2's table. Same
   abort-loudly error handling as `lv.py` (`ActionRangeError` for
   |u|>2.0, no state-floor concept here — angles/velocities have no
   floor — so no `StateFloorClampError` path applies to this world).
   `PendulumWorld` class + `WORLD` singleton, matching `lv.py`'s shape.
2. Tests: TC-WD1-01 (hand-verified reference), TC-WD2-01 (action
   changes outcome), TC-WD7-01 (two rollouts from the same seed/state
   are byte-identical), TC-WD7-02 (negative — injecting `numpy.random`
   into a scratch copy of the rollout must make the byte-identity
   check fail, proving it inspects something real).
