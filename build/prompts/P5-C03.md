# Build Prompt: P5-C03 — Horizon chart (full) + calibration chart

**In plain words:** two more of the four result charts.

**Chart 2** shows how wrong a model gets as it predicts further ahead, one panel per region. The
model's own error is a solid line. The world's own drift-apart curve is a black dashed line on the
same axes and in the same units, because only the gap above it is the model's fault. The two simple
baselines are grey lines. A labelled vertical line marks where each task stops grading exact paths
and switches to checking the overall pattern.

**Chart 3** asks whether "90% sure" really meant right 90% of the time. For each task it plots the
coverage actually achieved at the four stated confidence levels, one line per region, against the
diagonal labelled "perfectly honest". Above the panel it prints how wide the model's 90% ranges
were, so a model cannot look honest just by being vague.

Both charts draw only what the verdict says. The one exception is the error bars, which are
display arithmetic.

## Pinned decisions
- **Baselines are passed in by the caller.** The envelope has no "is baseline" field (judge §5:
  `{model_ref, model_name, is_fixture, verdict, meta}`), and reporting cannot read the registry.
  `wmj run` (P6-C01) knows which models are baselines. A baseline's block must have the same `dt`,
  the same regions and the same steps as the model's, or the chart is refused. The gap is recorded
  in the backlog.
- **Switch lines:** one per (task, region) entry of `climatology.per_task` whose `switch_step` is
  not null, labelled `"{task} switches to climate here"` (ADR-R2's wording). It is drawn on that
  region's panel.
- **Caption:** use `CHART2_FULL` when at least one switch line is drawn, and `CHART2_SCOPED`
  otherwise. Predator–prey has no switch step anywhere, and its caption must not say "past each
  task's marked step" about marks that are not there. This deviation is recorded.
- **Chart 3 layout:** one figure per (model, world) with one panel per task, sharing the y-axis
  from 0 to 1. The x-axis shows the four levels. The training region is a solid line and every
  other region is dashed, each with a direct label. The diagonal is labelled "perfectly honest".
  The header strip above each panel reads `sharpness (mean 90% width): {region} {w} · …`.
- **Chart 3 error bars:** ±1 binomial standard error *at the stated level*,
  sqrt(L × (1 − L) / n_trials). That is how far an honest model's coverage moves by luck at that
  trial count; the standard error of the observed proportion collapses to zero at a coverage of 0
  or 1. The y-label says so. The spec does not say which p to use, so this is recorded in the
  backlog.
- **Coverage is the joint-region coverage** (A39 item 1). The diagonal still applies.
- **Refuse** (`HorizonBlockError` / `CalibrationBlockError`) and write nothing on:
  - for Chart 2:
    - a malformed block;
    - a baseline that does not match the model's `dt`, regions or steps;
    - a switch step outside 1..H, or for an unknown region;
  - for Chart 3:
    - levels other than `[0.5, 0.8, 0.9, 0.95]`;
    - a coverage outside [0, 1] or of the wrong length;
    - `n_trials` < 1;
    - calibration and sharpness entries that do not pair up one to one;
    - a negative or non-finite width;
  - for either chart, names that are not file-safe (1–40 characters of `[A-Za-z0-9._-]`).

## TDD Approach
1. Outside-in first: render real judge blocks (`compute_error_vs_horizon`, `compute_climatology`,
   `compute_calibration` and `compute_sharpness` on the judge builder's input) through
   `render_horizon_charts` and `render_calibration_chart`. Read the saved SVG and caption back to
   check the switch labels, the reading rule, "perfectly honest", "about 90" and the sharpness
   strip. Commit red.
2. Unit tests: the same axes and units for the model and the reference (TC-JU3-01); log y; baseline
   curves in grey; switch lines at the right x; the caption choice; error-bar sizes; solid versus
   dashed regions; the header strip; the fixture label; each refusal.
3. Realistic-fixture variant: a pendulum-like curve that grows by 10⁸ over 5,000 steps with a switch
   at 4,750, three regions, coverage 0.0 and 1.0, and a fixture model.
4. Look at the renders. Then green, then review.

## Review Criteria
Computes no judgment; the model and the reference share axes and units; nothing hides data; the
captions are true of the chart drawn; no pyplot; imports stay within the reporting allowlist, with
the gate run in the same command as every commit; an "In plain words" docstring.
