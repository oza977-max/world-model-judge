# Build Prompt: P5-C01 — Style + captions

**In plain words:** before any of the four result charts is drawn, two shared pieces must be right,
because every chart uses them. (1) *The look*, and above all the rule that a chart containing a
deliberately broken test model always says so in words on the image itself. This chunk turns that
from a habit each chart must remember into a check the save step enforces: a figure that holds
fixture output cannot be saved without the label, and a figure without fixture output cannot be
saved with it. (2) *The words under each chart*: the fixed caption templates for all four charts,
with their numbers filled in by checked functions, never improvised, never longer than three
sentences.

## Chunk Summary
From `specs/implementation-guide.md` P5-C01: extends P2-C05's minimal `reporting/style.py` to the
full shared style, colour semantics, `mark_fixture`, and the caption templates. *Spec:* reporting
ADR-R1, ADR-R3, ADR-R4. *Tests:* TC-RP8-01 (fixture label present in the figure object before
save), TC-RP5-01 (caption templates ≤ 3 sentences; the judged reading half is a human pass at
P6-C03), TC-MU4-01 (chart surface).

## Spec Excerpt (pinned decisions)
- ADR-R1 colours: model dark blue; baselines grey; divergence reference black dashed; misses red
  circles; band fills green/amber/red; fixtures orange *and* labelled.
- ADR-R4: any figure containing fixture output draws the verbatim sentence inside the axes, and
  fixture curves use the fixture colour and a `FIXTURE:` name prefix. Implemented once in
  `mark_fixture`, and called whenever the envelope's `is_fixture` says so: one code path, no
  per-chart discretion.
- ADR-R3 templates (verbatim except Chart 1, below). Chart 3: "When the model said it was {level}%
  sure, was it right that often? Of every 100 ranges it drew at 90% confidence, about 90 should
  contain the true outcome. The solid line is familiar territory; the dashed line is territory it
  never saw in training — the honest model's lines both hug the diagonal." Chart 4: "Ordinary
  accuracy and the judge's trust horizon, side by side. {disagreement_sentence}", with either
  "Ordinary error says {A} and {B} are equals; the judge does not." or "On this run the two rankings
  agree — the interesting case did not occur, and saying so plainly beats manufacturing one."
- **Chart 1, amended (deviation, recorded in the backlog):** ADR-R3's text ("Each vertical bar is
  what the model said was 90% likely for one test run; the dot is what actually happened…")
  describes per-trial bars. Since the owner's ruling of 2026-10-22 (A39 item 9), the chart plots
  each trial's whole-answer miss, in the model's own stated sizes, against one fixed line. The
  caption must describe the chart that is drawn: "Each dot is one test run: how far the outcome
  landed from the model's guess, measured in the model's own stated error sizes and combined over
  everything it predicts. Dots above the line fell outside the range the model called 90% likely —
  those misses are circled in red. A model this confident should miss about {expected} of {n} times
  — it missed {observed}, which lands it in the {band} band drawn on the right."
- Slot rules: `expected` is the verdict's float n·p, shown rounded to a whole number ("about"; this
  is display arithmetic); `n` is an int ≥ 1; `observed` is an int in 0..n; `band` is one of
  green/amber/red; `level` is one of 50, 80, 90, 95; `A` and `B` are display names. Booleans are
  refused where an int is expected.

axes text.

## Review Criteria
- **One code path:** no renderer can save a fixture figure without the label, and the check reads
  the figure object, not the renderer's intent.
- **Templates:** each is verbatim from ADR-R3 except the recorded Chart 1 deviation. Each filled
  caption is ≤ 3 sentences by the module's own splitter, and the splitter is not fooled by slot
  values.
- **Slot validation fails loudly** on missing, extra, wrong-type, out-of-range and boolean-for-int
  values.
- **Reporting imports** stay within the gate's allowlist (TC-NF6-10: no `os`). No pyplot. No
  global state beyond the documented rcParams.
- **Plain words:** module docstrings carry an "In plain words" paragraph.
