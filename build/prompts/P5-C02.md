# Build Prompt: P5-C02 — Exception plot (Chart 1)

**In plain words:** the project's primary chart. For one model, one region, one task and one of the
two judged steps, it shows every one of the 200 test runs as a dot: how far the outcome landed from
the model's guess, measured in the model's own stated error sizes. A line marks the edge of the
range the model called 90% likely, and the misses are circled in red. On the image itself it states
the expected number of misses beside the actual number and names the colour band that puts it in,
with a small scale on the right showing where the count sits among green, amber and red. If the
model is a deliberately broken test fixture, the image says so in words. The chart draws only what
the verdict says; it computes no judgment of its own.

## Spec Excerpt (pinned decisions)
- **One figure per (model, world, region, task, horizon_step)**, each with its own caption (ADR-R2:
  "two Chart-1 panels, both captioned, side by side"; the side-by-side arrangement is the results
  page's job, P5-C04).
- **File names:** `charts/{world}-{model}-exceptions-{task}-{region}-h{step}.png` and `.svg`;
  `captions/` gets the same stem with `.txt` (ADR-R5's `{world}-{model}-{chart}`).
- **X:** trial index 0..n−1 in the array's order (the trial-generation order). **Y:**
  `outcome_distance` as given. **The line:** `band_hi` as given, over `band_lo` (always 0). **Misses:**
  red open circles exactly where `is_exception` is true, drawn as-is, never re-derived.
- **Header strip:** `region: {region} · observed exceptions: {observed} · expected: {expected} of {n}
  · band: {BAND}`, where `expected` uses the same display rule as the caption. If
  `low_side_sharpness_flag` is set, it appends ` · {observed} misses — but see sharpness: possible
  hedging` (§7).
- **Inset scale on the right:** count bands from `bands` (green [g_lo, g_hi]; amber both sides; red
  outside), with a marker at `observed`. This is display arithmetic only (§4).
- **Fixture:** `display_name` in the title, `line_colour` for the dots, `mark_fixture(ax)`, and
  `save_figure(..., contains_fixture=is_fixture)`.
- **Refuse** (`ExceptionBlockError`), drawing nothing: a missing or extra key, unequal array
  lengths, a length other than `n_trials`, `sum(is_exception) != observed`, a band not in
  green/amber/red, non-boolean flags, an exceptions entry with no trials entry (or two), and a
  non-finite or negative distance.

## Framework Reference
Matplotlib 3.11: `Axes.scatter(x, y, s=, facecolors='none', edgecolors=)`; `Axes.plot`;
`Axes.fill_between`; `Axes.inset_axes([x0, y0, w, h])` in axes coordinates (x0 > 1 puts it right of
the axes); `Axes.axhspan(ymin, ymax, color=)`; `Axes.set_title(loc="left")`; `Figure.suptitle`. The
SVG keeps text as text (`svg.fonttype: none`), so the acceptance test can read the header from the
saved file.

## TDD Approach
1. **Outside-in acceptance test first:** render a real envelope (verdict blocks made by the real
   judge, `compute_exceptions_and_trials` on the judge test builder's input) to a temp `out/`. Read
   back the saved SVG and assert that it shows the expected count, the observed count and the band
   name (TC-RP1-01). Also render a fixture envelope and assert the fixture sentence is in the SVG
   (TC-RP8-01). Commit it red.
2. Unit tests: pairing and validation refusals; header text, including the hedging note; misses
   circled exactly where flagged; the inset marker at the observed count; file names.
3. Realistic-fixture variant: a 200-trial block with huge outliers (1e6 stated sizes), zero misses,
   all misses, distances of exactly 0, and a 3-region verdict.
4. Green, then review.

## Review Criteria
- The chart computes no judgment: every number drawn comes from the verdict, and the only
  arithmetic is display arithmetic.
- `is_exception` is drawn as given; the observed count is cross-checked, not recomputed for display.
- The header and the caption agree with each other and with the verdict.
- No pyplot; reporting imports stay in the allowlist (`tests/gates/test_import_graph.py`).
- An "In plain words" docstring; tests for every refusal.
