## Scope decisions this chunk makes

- **Who computes the error curve.** Reporting "never computes a
  judgment metric" (reporting §4); the real `error_vs_horizon` block
  is the judge's (JU-3, P4-C05). Nothing judge-side exists yet, so the
  harness computes a **scoped stand-in with exactly the judge's block
  shape** — `wmj/harness/preview.py`: for each LV region, draw
  N eval starts (`seeds.rng_for("lv", region, "eval-starts")`), roll
  the truth forward under null actions, roll persistence forward (its
  multi-step forecast is the start state held constant — "nothing
  changes"), take the per-step median normalised error across trials
  (`distance()`, ADR-W3), and attach P2-C03's median separation as
  `divergence_reference`. `horizon_plot.py` draws that dict and
  computes nothing. When the judge's real block exists, the renderer
  is unchanged — only the producer swaps.
- **CRPS/skill wiring.** The guide says this chunk wires `skill.py`
  too. The preview computes one-step CRPS for persistence and linear
  on the same trials and reports persistence's skill-vs-linear on
  stdout as the command's summary line — a real call path over real
  trajectories, without inventing an artefact under `out/` that no
  spec names (captions are fixed templates and must not carry
  improvised numbers, ADR-R3).
- **Persistence spread "extension".** P1-C02 already implements
  ADR-M2's rule (per-dimension std of one-step training changes).
  ADR-M2 does not pin `ddof`. This chunk makes the fit an explicit,
  public `fit_persistence_spread(training)` with **`ddof=1`** (sample
  std — the training set is a sample of the world, and the ensemble
  spread elsewhere in ADR-M3 also uses Bessel's correction) and a
  **fail-loudly guard**: a zero-variance dimension would yield spread
  0, which CRPS rightly refuses; the fit raises `DegenerateSpreadError`
  instead of emitting it. The `ddof` choice is recorded as backlog
  candidate A8 (spec should pin it; it changes bytes).
- **Reduced-scale options.** `wmj chart-preview` takes `--n-starts`,
  `--n-trials`, `--horizon` (full-scale defaults: 64, 200, 700) so the
  acceptance test runs in seconds while the real command runs the
  spec's numbers.
- **PNG bytes are not byte-identity-claimed** (ADR-R5/§7); SVG bytes
  are, with both pins. The acceptance test asserts SVG identity across
  two in-process renders; the separate-process check is TC-RP7-02 at
  P5-C04.

## Review Criteria

Tier 1: Keeling (ADR-R1/R2/R3 cited exactly; the scoped caption is the
template minus one clause, not a rewrite); McConnell (fail loudly on a
degenerate spread; no silent clamps). Tier 2a (reporting): Tufte /
Few via ADR-R1 (data-ink, direct labelling, log scale for legibility —
TC-RP2-01). Tier 3: Ramalho; Goldberg (SVG byte identity is an
ordering discipline: fixed hashsalt, no date, deterministic input
arrays).
