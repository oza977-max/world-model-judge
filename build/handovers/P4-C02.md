# Handover: P4-C02 — the skill block (CRPS and skill against the two baselines)

**In plain words:** the judge's first number. For every region of the world it scores the model's
whole forecast — the guess and its stated uncertainty together — one step ahead with a rule that
cannot be gamed (CRPS: being confidently wrong costs more than being modestly wrong, and so does
hedging with a wide range), scores the two reference forecasts ("nothing changes" and "straight-line
continuation") the same way, and reports how much better the model is: 0 is "no better than the
reference", 1 is "essentially perfect", negative is "worse". The judge cannot see any other model,
so no third comparison can appear. Anything that would turn the score into nonsense (a zero error
bar, an overflow, a number that is not a number) stops the run with a named refusal instead.
