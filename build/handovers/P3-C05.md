# Handover: P3-C05 — the three broken test models (fixtures)

**In plain words:** three models that are broken on purpose, each by exactly one
thing, so the judge can later be shown to catch exactly that thing. `fx-overconfident`
is right but cocky (its error bar is a quarter of Model A's). `fx-honest-rough` is
rougher but honest (its guess is jittered by noise twice the size of Model A's error
bar, and its bar is widened by exactly the amount that makes that honest). `fx-brittle`
is excellent at home and catastrophic away (outside the region it was trained on it
just says "nothing changes"). Each is Model A itself — the same trained network object —
plus that one change. They are labelled as fixtures: detecting a failure we built in is
a passing test, never a discovery (MU-4).
