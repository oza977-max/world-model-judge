# Handover: P4-C05b — the climatology table and the measured invariant bins (harness half of P4-C05)

**In plain words:** the judge's "does the model still look like the world?" test needs a reference
table: for each of sixteen ranges of the world's conserved quantity (energy, or the predator-prey
"orbit number"), what states does the world typically visit, and how widely? This chunk builds that
table by starting the true world from 200 seeded points across the training region and running each
1,000 steps with no actions, and works out, for every test trial at every step, which range the
*true* state is in, measured afresh each step because a kick moves a trial into a different range.
It also measures how well the true world agrees with its own table — the best any model can do —
which turned out to be the most important thing this chunk found (owner decision D21).
