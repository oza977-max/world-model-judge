**Status:** Complete. All Hard Gates satisfied. 26/26 tests green.

## What this chunk delivers

In plain words: this chunk is the ground floor everything else stands
on — nothing here talks to a world, a model, or the judge. It's the
plumbing that makes every later chunk's output trustworthy: one way
to turn data into bytes that come out identical every time
(`canonical_serialize`), one way to hand out random-number streams so
adding a new model never silently reshuffles another model's training
(`SeedSource`/`component_key`), and one guard that forces NumPy's math
library to run single-threaded before it can introduce nondeterminism
of its own (`thread_guard`).

- `pyproject.toml` + `requirements.lock` — pinned dependency set
  (`numpy>=1.26,<2.0`, `matplotlib>=3.8,<4.0`; dev `pytest`), src
  layout, pytest config. Lockfile is real `pip freeze` output (15
  packages, direct + transitive), stripped only of the local editable
  install line.
- `src/wmj/errors.py` — `WmjError`, the shared base every package's
  own exceptions subclass.
- `src/wmj/harness/serialize.py` — `canonical_serialize`,
  `NonFiniteValueError`. Sorted keys, UTF-8, `\n` newlines, no
  trailing whitespace, `.tolist()`/`.item()` for NumPy types,
  `json.dumps(sort_keys=True, allow_nan=False)` as the sole
  float-rendering call (cross-cutting ADR-002 rule 4).
- `src/wmj/models/base.py` — `component_key(*parts)` and `SeedSource`
  (frozen dataclass: `run_seed`, `my_name`, `rng`, `rng_for`),
  content-addressed seed derivation, pinned exactly to the ADR-002
  rule 2 construction (blake2b digest_size=8 → one big-endian int).
- `src/wmj/harness/thread_guard.py` — `ensure_single_threaded()` /
  `assert_single_threaded()`, the three `*_NUM_THREADS` env vars
  (cross-cutting ADR-002 rule 1).
