# Handover: P3-C04 — Model B ("ensemble") and the P3-C02 re-open

**In plain words:** the second practice model: five copies of one small network,
each started from a different random point and shown the examples in a different
order. Their average is its guess; how much they disagree, with a small standard
correction for having only five, is its error bar. Built to be as accurate as
Model A but to get its error bar the other way. Run for real it is about as
accurate as Model A (slightly more accurate) and **far over-confident** — the
contrast the whole experiment exists to expose; nothing was tuned to produce it.
Alongside it, the two simple baselines got the two small flags the spec now
requires (`stateless`, and `predict_batch` on persistence), and a registry-wide
test now checks that every model that says it is stateless batches bit-identically.
