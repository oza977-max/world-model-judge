# Handover: P5-C03 — Horizon chart (full) + calibration chart

**In plain words:** two more of the four result charts are built.

**Chart 2** shows how wrong a model gets as it predicts further ahead, with one panel per region:
- the model's own error is a solid line;
- the world's own drift-apart curve is a black dashed line on the same axes and in the same units, because only the gap above it is the model's fault;
- the two simple baselines are grey lines;
- a labelled dotted line marks where each task switches to checking the overall pattern. The label names its step.

**Chart 3** asks whether "90% sure" meant right 90% of the time:
- one panel per task;
- one line per region, with training solid and the others dashed;
- the "perfectly honest" diagonal;
- error bars showing how far honest luck alone moves a point;
- a strip above each panel saying how wide the model's 90% ranges were, so a vague model cannot look honest.

Both charts draw only what the verdict says. A block that does not add up is refused before anything is drawn or written.

Every Important finding in this chunk was a layout defect visible only on the image, and three of the six came from my own fixes (new margins, a two-line label).
