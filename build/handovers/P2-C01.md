## Scope decision: worlds-side vs judge-side distance

ADR-W3 declares one canonical distance formula but, per ADR-003 (judge
imports nothing but stdlib+numpy), it will be implemented twice by
design — once here (worlds owns `scale`, and P2-C03's divergence
benchmark needs it next) and once in `wmj/judge/distance.py` (ADR-J5,
Phase 4). This is the same deliberate-duplication pattern already used
for `WorldContext`/`Task`/`RegionSpec`, not a new decision.

**Honest disclosure:** `distance`/`within_tolerance` have zero callers
in `src/` right now — this is build-ahead-of-consumer, confirmed
clean by independent review, with P2-C03 named as the next consumer.
