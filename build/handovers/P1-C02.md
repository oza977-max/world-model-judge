## What this chunk delivers

In plain words: this is the first time the whole pipe carries water.
Type `python -m wmj run --skeleton` and a real predator-prey world gets
simulated, two baseline models get trained from seeded data, one is
scored against the other with a real statistical scoring rule (CRPS),
and the result is written to a file that comes out byte-for-byte the
same every time you run it. Nothing here is the *real* pipeline's
numbers — it's deliberately the smallest slice that proves every seam
is wired correctly, before any of the real constants exist.

- `src/wmj/worlds/base.py` — `RegionSpec`, `OutRegion`, `Task` frozen
  dataclasses (worlds spec §4.3).
- `src/wmj/worlds/integrator.py` — `rk4_step`, the one shared
  fixed-step RK4 every ground-truth generator in the project will use
  (worlds ADR-W1).
- `src/wmj/worlds/lv.py` — the LV world: constants, `transition`
  (impulse-then-integrate, ADR-W2), `conserved`, `regions`, `tasks`,
  and (added post-review) loud aborts on a state-floor excursion or an
  out-of-declared-range action, plus import-time region-spec
  validation — all per worlds §7.
- `src/wmj/worlds/errors.py` — `StateFloorClampError`,
  `ActionRangeError`, `RegionSpecError`.
- `src/wmj/models/base.py` (extended) — `Prediction`, `WorldContext`,
  `TrainingData` frozen dataclasses (models ADR-M1).
- `src/wmj/models/baselines.py` — `persistence_factory`,
  `linear_factory` (models ADR-M2's mean rules + minimal spread).
- `src/wmj/judge/_normal.py` — `Phi`, `phi`, the four z_p constants.
- `src/wmj/judge/skill.py` — `crps_gaussian`, `skill_score` (judge
  ADR-J1's closed form).
- `src/wmj/harness/skeleton.py` — the throwaway-by-design orchestration
  that builds and writes the skeleton report.
- `src/wmj/harness/cli.py` — `main(argv)`, the `run --skeleton`
  subcommand.
- `src/wmj/__main__.py` — thread guard first, then delegates to the
  CLI.

## Scope decisions (see build/prompts/P1-C02.md for full rationale)

This chunk is explicitly smaller than the real pipeline: 8 training
trajectories × 50 steps (not 2000×700 — no `prereg/` numbers exist
yet), 20 one-step eval trials, scores persistence against linear
(not both baselines against a learned model — none exists until Phase
3), and writes a distinct `wmj-skeleton/0` schema, not the pinned
`wmj-verdict/1` Verdict. No `wmj.models.registry` yet — the CLI calls
the two factories directly by name.

## Review passes (Hard Gate 3, Phase 2 — independent review convergence loop)


**Pass 1** found 2 Important findings (both fixed) and 4 Minor notes
(3 fixed inline, 1 — the `RegionSpecError` guard's untested failure
path — fixed after pass 2 flagged it, see below):

- **Important:** `transition()` silently clamped a state-floor
  excursion via `np.maximum` instead of aborting, contradicting worlds
  §7's "one rule, no scope exceptions." Also missing: `ActionRangeError`
  for an out-of-declared-range action, and region-box validation at
  construction. **Fixed:** new `wmj/worlds/errors.py`
  (`StateFloorClampError`, `ActionRangeError`, `RegionSpecError`, all
  subclassing `WmjError`); `transition()` now raises on both an
  out-of-range action and any floor excursion (checked post-impulse
  and post-RK4-step); `lv.py` validates its own hardcoded `RegionSpec`
  once at import time.
- **Important:** TC-WD1-01's hand-verified reference state (4.5, 2.0)
  silently deviated from worlds.md's own pinned (4.0, 2.5), which the
  reviewer independently verified is this world's exact equilibrium
  point (derivative exactly zero there) — a degenerate RK4 test that
  cannot catch an integrator bug. **Fixed:** documented the deviation
  and its reasoning in `test_lv.py`'s module docstring and this
  prompt's Post-review addendum, rather than silently swapping the
  value or amending the already-reviewed spec mid-build.
- **Minor (fixed):** `NonPositiveSpreadError`'s message lacked a
  requirement-ID citation; no multi-dimensional `crps_gaussian` test
  existed; `__main__.py`'s docstring didn't follow the "In plain
  words" convention.

**Pass 2** confirmed both Important fixes with independent evidence
(re-derived the equilibrium point algebraically, traced the
`_validate_region_spec` call site to confirm it runs at import time
and would genuinely catch a bad spec, re-ran the full suite and the
real CLI twice). Found **zero new Critical/Important issues**. One new
Minor: the `RegionSpecError` guard's two raise branches were never
exercised by a test (only the already-correct live spec was checked
against the invariants). **Fixed:** added
`test_validate_region_spec_rejects_a_box_touching_the_floor` and
`test_validate_region_spec_rejects_an_out_region_overlapping_training`
to `test_lv.py`, directly exercising both failure branches.

**Converged: pass 2 returned 0 new Critical/Important findings.**
