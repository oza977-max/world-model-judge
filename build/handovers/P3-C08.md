# Handover: P3-C08 — the action-response check and the fourth fixture (`fx-action-blind`)

**In plain words:** a model is only a simulator if what you *do* changes what happens.
So every model now faces one extra check: hold the starting state still, give it two
different actions from the range it was trained on, and see whether its answer moves by
more than floating-point noise; a model that never moves is flagged **action-blind**.
Alongside it, the fourth broken test model, `fx-action-blind` — Model A (the same trained
network) with the action thrown away — so we can show the check catches exactly that. It
is test equipment, never a finding (MU-4). **The question carried since Round 10 — is the
smaller predator–prey lever still enough? — is answered yes by running it for real:** the
real Model A responds on all 48 probes by about 2–5% of the world's scale per step on predator–prey (16–32% on the pendulum), more
than seven orders of magnitude above the tolerance; its action-blind twin changes by exactly
zero and is flagged (`build/measurements/p3-c08-action-response.md`).
