# Handover: P5-C02 — Exception plot (Chart 1)

**In plain words:** the project's primary chart is built. For one model, region, task and judged
step, every test run is a dot: how far its outcome landed from the model's guess, in the model's
own stated error sizes. A line marks the edge of the range the model called 90% likely, and the
verdict's misses are circled in red. A strip above states "observed exceptions · expected · band",
with the hedging warning on its own line when the verdict flags it. A scale on the right shows where
the count sits among green, amber and red, with the expected count dotted. A deliberately broken
test model's chart says so in words. The chart draws only what the verdict says. A block that does
not add up is refused before anything is drawn or written.
