# Handover: P3-C03 — Model A ("direct")

**In plain words:** the first of the two practice models that really learn. A
small neural network looks at where the world is and what push is applied, and
says two things for every quantity: how it expects the quantity to change, and
how wrong it expects that guess to be (its own error bar). It learns from the
shared homework the harness hands every model, with a loss (β-NLL) that stops a
stubbornly large error bar excusing a bad guess; before it learns anything, its
learning arithmetic is checked once against brute-force numbers. It can predict
many runs at once with exactly the same numbers as predicting them one by one.
Also built: the once-only, blind check "is 50,000 training examples enough?" —
and running it for real produced a finding that needs your decision (D18):
**the check, as pre-registered, mostly measures random-seed luck.** No recipe
value was changed.

## Retrospective
- The code was right from the first review; ten passes were spent making the tests fail when a rule breaks. The decisive lesson: write the tests that exercise the *real regime* (real error-bar sizes, real kick sizes, real epoch counts, all dimensions, all rows) at the start, not the small-fixture regime — that class accounted for passes 3 and 6–9.
- A systematic *class* audit (pass 8) and a real-scale gate (pass 9) were more effective than another random mutant sweep.
- Running the pre-registered test for real turned out to be the most valuable single thing in the chunk (D18).
