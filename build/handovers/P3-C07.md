## What this chunk delivers

In plain words: the machinery that makes MU-6 / JU-11 mechanically true —
you cannot move a threshold after seeing results if the recipe, the ranking
prediction, and the thresholds were committed, content-frozen, and
timestamp-ordered before the judged run. Three parts, all in the harness
(the orchestration edge — it may read git and files; the pure judge may not):

- `src/wmj/harness/derive_thresholds.py` — the JU-11 bands **computed** from
  the exact binomial CDF for Bin(200, 0.10): green `[12, 29]` (each tail ≤
  2.5%, outside-prob 3.31%), amber-outer `[8, 35]` (each tail ≤ 0.05%,
  outside-prob 0.087%), red beyond. Plus the per-world
  `sharpness_hedge_threshold` (= the world's scale vector) and
  `agreement_threshold` (1.0). `write_thresholds` writes
  `prereg/thresholds.json` byte-reproducibly via the canonical serializer.
- `src/wmj/harness/prereg.py` — `check_prereg`: every `prereg/` file is
  committed, not dirty; its first-added commit (resolved with `git log
  --reverse --diff-filter=A`, so a delete-then-readd cannot masquerade)
  strictly precedes the run; its content hashes equal to that first-add
  blob. Every unrigged model's name appears as a whole token in the
  committed recipe and prediction; baselines/fixtures are exempt. Plus
  `read_matching_margin` + `within_matching_margin` (the MU-5 0.05 check).
- `prereg/recipe.md`, `prereg/prediction.md`, `prereg/thresholds.json` — the
  committed pre-registration artefacts, naming `direct` and `ensemble`.

## Two pinned values the spec left open (backlog A12)

- **`epochs: 100`** — models §4 pinned `training_trajectories: 2000` but left
  the epoch count open; 100 is a round, fixed-in-advance modelling choice.
  Its convergence-and-runtime feasibility (NF-2) is validated at P3-C03/C06;
  the P3-C07→C03/C06 ordering pins it before its runtime is measurable — an
  honest ordering tension (A12), resolvable by an open recipe revision
  before any judged run if needed (with the content-hash implication noted).
- **`sharpness_hedge_threshold = scale`** — judge ADR-J4 pinned only "from
  the world's scale vector," not the formula. Chosen and documented.

Both flagged for design-review ratification (A12).

**Pass 1** (1 Critical, 2 Important, 3 Minor) — all fixed:
- **Critical — substring name match.** `model.name not in recipe_text`
  passed a model named `"ir"` because "direct" contains it — a silent bypass
  of MU-6's per-model guarantee. Fixed with `_declares()`, a whole-token
  regex (`re.escape` + a `[A-Za-z0-9_-]` delimiter class that also handles
  hyphenated names). Regression tests added (substring rejected, hyphenated
  accepted).
- **Important — entry files must be certified.** `check_prereg` now refuses
  unless `{recipe.md, prediction.md} ⊆ files`, so the entry check never reads
  uncommitted text. Test added.
- **Important — git errors wrapped.** `_git`/`_blob_at` wrap
  `CalledProcessError`/`FileNotFoundError` in `PreregError` (a non-repo dir
  now fails with a clear message, not a raw crash).
- **Minors** — deleted-working-tree file now raises `PreregNotCommittedError`
  (not raw `FileNotFoundError`); the dirty-file test tightened to the exact
  exception; an end-to-end delete-then-readd test added through `check_prereg`.
