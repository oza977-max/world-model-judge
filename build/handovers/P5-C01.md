# Handover: P5-C01 — Style + captions

**In plain words:** two shared pieces every result chart will use are now finished.
(1) The rule that a chart containing a deliberately broken test model must say so in words on the
image is now enforced where every chart is saved. A figure holding fixture output cannot be saved
without the label. A figure of real models cannot be saved wearing the label, or showing anything
in the fixture orange or named `FIXTURE:`. A hidden label does not count. (2) The words under each
chart are fixed templates for all four charts, and checked functions fill in their numbers. A count
that cannot be true, an unknown band or an unused confidence level is refused, never printed.

## Retrospective
The one Important I introduced myself came from a blanket auto-fix (`ruff --fix`) run *after* the gate run, then committed without re-running the gate. Lesson: run the gates after the last edit, not before the lint pass. The independent reviewer's "the flag is only the caller's claim" was the more valuable catch: the first design enforced the rule in one place but still trusted the caller about the one fact that matters.
