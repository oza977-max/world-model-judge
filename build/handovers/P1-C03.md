## What this chunk delivers

In plain words: this chunk builds the tripwires that keep the rest of
the build honest. Before this chunk, nothing stopped a future model
file from quietly importing the harness, or a judge file from quietly
reading the clock, or the ground-truth simulator from silently drifting
onto a different step size than the models it's compared against. Now
those things fail loudly, at test time, before they ever reach a real
run.

- `tests/gates/_ast_utils.py` — shared AST-walking helpers (import
  names, joined module+name comparisons, banned-identifier scan,
  numpy.random usage scan, metaclass-keyword scan) every check below
  is built from.
- `tests/gates/test_import_graph.py` — the full TC-NF6 family:
  - **TC-NF6-01/02/03** — the judge package's import allowlist
    (`{numpy, math, dataclasses, typing}`), banned-identifier scan, and
    wholesale `numpy.random` ban.
  - **TC-NF6-04** — the 18-fixture evasion regression corpus under
    `tests/gates/fixtures/`.
  - **TC-NF6-06** — the clean-pass guard (real judge/models source
    never false-positives).
  - **TC-NF6-07/08/09** — the models package's full outward-import
    allowlist (not just a denylist of the three named forbidden
    directions), correcting a real gap in cross-cutting.md's own claim
    along the way (see Post-review addenda below).
- `tests/gates/_dt_alignment.py` + `test_wd3_dt_alignment.py` —
  TC-WD3-01 (skeleton scope) and TC-WD3-02 (negative): the ground truth
  and every model must share one integrator and one step size.
- `tests/gates/test_byte_identity.py` — TC-NF1-01 (skeleton scope):
  ten separate-process runs of `python -m wmj run --skeleton`,
  byte-identical.

## Review passes (Hard Gate 3, Phase 2 — independent review convergence loop)

```
Review passes: [(1, 4), (2, 1), (3, 1), (4, 1), (5, 1), (6, 0)]
```

This chunk's review loop ran six rounds — longer than P1-C01 (two) or
P1-C02 (two) — because the security-relevant nature of an
identifier-enumeration lint invites genuine, escalating adversarial
review, and each round found one real, independently-executed bypass
rather than a documentation or convention nit. This is the pattern
Fagan's own inspection research predicts for a defect class that
rewards deeper adversarial passes; it converged, it did not run away.

**Pass 1** found 4 Important findings, all fixed:
- A fixture claimed to demonstrate "string-concatenated identifier"
  evasion but was actually only caught via unrelated already-banned
  identifiers (`getattr`/`__builtins__`) — confounded, not independent
  evidence.
- TC-WD3-01's "both call sites call `lv.transition`" test could only
  prove at least one did (a module-wide set check).
- TC-WD3-01's dt-alignment check was circular (`lv.WORLD.dt == lv.DT`
  is guaranteed true by construction).
- The models-side import gate was a 4-item denylist, not the full
  allowlist cross-cutting.md's own ADR-003 text claims — `import os`
  would have sailed through uncaught.

**Pass 2** confirmed findings 2–4 solid, but found the fix for finding
1 was not just incomplete but *wrong* — its docstring claimed
string-concatenation evasion was inherently undetectable, and pass 2
disproved this by executing a real bypass: `math.__dict__["s"+"qrt"]`
reaches a computed attribute using zero of the then-banned 13
identifiers. **Fixed:** added `__dict__`/`__getattribute__` to
`BANNED_IDENTIFIERS`, added a dedicated fixture, corrected the false
docstring claim.

**Pass 3** confirmed the `__dict__` fix solid, then — per its own
mandate to keep hunting — found a bypass of a *different kind*: a
custom metaclass's `__new__` receives the class-body namespace as an
ordinary function parameter, reaching the same capability with zero
banned identifiers touched. The user was consulted directly (this
finding raised a real strategy question — identifier-enumeration is
inherently reactive) and chose to patch it rather than defer it.
**Fixed:** added a structural (non-identifier) check,
`scan_metaclass_usage`, banning `class X(metaclass=...)` outright.

**Pass 4** confirmed the metaclass fix solid, then — explicitly asked
to judge whether further hunting was diminishing returns — found
`locals()` missing, the third sibling of the already-banned
`globals`/`vars`. Judged the same "obvious sibling" caliber as pass
2's finding, not new trick-hunting. **Fixed:** added `locals` to
`BANNED_IDENTIFIERS`.

**Pass 5** confirmed the `locals()` fix solid, then found a more
consequential gap: `except X as e: e.__traceback__.tb_frame` hands
over a live frame exposing `f_globals`/`f_locals`/`f_builtins` with no
import and no previously-banned identifier — reaching the *entire
builtins table* in one hop, demonstrated with a real filesystem read.
Checked against both possible reasons to defer it (the import
allowlist; the disclosed `ctypes` residual) and cleared neither.
**Fixed:** added `__traceback__`, `tb_frame`, `tb_next`, `f_globals`,
`f_locals`, `f_builtins`, `f_back`.

**Pass 6** (explicitly framed as final) verified the traceback/frame
fix solid with fresh execution of both pass-5 PoCs, then checked two
specific, comparable-severity candidates (generator/coroutine frames;
`sys.exc_info()`) and ruled both out with evidence — generator/
coroutine frames lead nowhere without an already-banned frame
accessor; `sys` is already excluded by the separate import-allowlist
gate. **Converged: zero new findings, explicit "converge now, no pass
7" verdict.**

**Net effect:** `BANNED_IDENTIFIERS` grew from the literally-pinned 13
(cross-cutting.md ADR-003) to 23, plus one structural check
(metaclass) and two allowlist corrections (`wmj.errors`, `hashlib` for
the models gate). Every addition is documented in
`test_import_graph.py`'s own module docstring with the executed
evidence behind it, and every one is flagged as a candidate for a
future design-review correction to cross-cutting.md's pinned text —
not silently edited into the already-reviewed spec document.
