# Handover: P3-C09 — Batched world step + kick generator + action-axis region + kicked benchmark

**In plain words:** the two worlds can now step many runs at once with
exactly the same numbers as stepping them one by one. Every run's pushes
("kicks") come from one seeded generator — small, occasional kicks that
were measured never to crash predator–prey. Each world has a third test
region, `out-large-action`: familiar starting states, but kicks bigger
than anything the models trained on. The "how fast the world drifts on
its own" benchmark now gives both twin runs the same kicks, so it compares
like with like. Nothing is trained or judged yet; this is the plumbing the
training data (P3-C06) and the judged run (P6-C01) need.
