# P2-C04 — Region labelling — Handover

**Status:** Complete. 159 fast tests green (16 new).

## What this chunk delivers

In plain words: every evaluation trial now gets a two-part tag —
*which declared region its starting point came from* (the key used to
pick the right divergence curve and climatology table) and *whether it
left the territory the models were trained on, and on which axis*
(the state wandered outside the training box, an action fell outside
the trained range, both, or neither). Without the "which axis" part,
"it failed out of region" would hide whether the model met an
unfamiliar situation or an unfamiliar command — WD-5's "say which"
clause.

- `src/wmj/harness/regions.py` — `state_in_training_box`,
  `actions_in_trained_interval` (closed on every edge, any-step
  violation counts), `attribute_axis` (ADR-W4's four values),
  `label_trial` → the canonical `{"region_name", "axis"}` dict,
  `UndeclaredRegionError` (fail loudly on a name the world never
  declared).
- `tests/unit/harness/test_regions.py` — TC-WD5-01 (just inside /
  just outside / exactly on all four corners), TC-WD5-02 (state inside,
  action outside the *trained* interval but inside the world's declared
  range → `"action"`), the four-value axis table, LV and pendulum
  spec-driven cases, `"both"`, the undeclared-name negative.

## Scope decision, recorded

`region_name` is an **input** (the region the harness drew the start
for, per cross-cutting ADR-004's per-region sampling loop), validated
against the world's declared names — not re-derived from the state.
This is what makes TC-NF1-09 ("every declared region appears in
`region_labels`") achievable by construction. A start drawn for an
out-region can never label `axis=None`, because out-region boxes are
validated disjoint from the training box at import (`lv.py`,
`pendulum.py`); the reviewer checked this against the actual box
constants, not just the claim.
