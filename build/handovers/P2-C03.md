## What this chunk delivers

In plain words: before any model is judged, the harness measures how
fast each world *itself* pulls two almost-identical starting points
apart. That curve is the yardstick every later error-vs-horizon chart
is drawn against — without it, "the model drifted from the truth"
cannot be separated from "nobody could have stayed on the truth". The
same run also checks that the integrator conserves what the world says
it should conserve, and aborts loudly if it does not.

- `src/wmj/worlds/divergence.py` — `perturb` (ADR-W3's sign-alternating
  relative nudge), `separation_curve`, `median_separation_curve`,
  `conserved_drift`, `assert_drift_within_bound` (`DriftBoundError`;
  NaN drift raises, not passes).
- `src/wmj/harness/benchmarks.py` — `sample_region_starts`,
  `build_divergence_artefact` in exactly worlds §5's shape (64 seeded
  starts per declared region, `"benchmark-starts"` purpose key, null
  actions, per-step median). Returns the dict; writing under `out/` is
  reporting's job (design-review-008 C8).
- `tests/gates/test_benchmark_full_scale.py` (`slow` marker registered
  in `pyproject.toml`) — the spec's real numbers, run at full scale.
- Tests: `tests/unit/worlds/test_divergence.py` (TC-WD3-03, TC-WD4-01,
  TC-WD4-02), `tests/unit/harness/test_benchmarks.py`.

## Deviations, executed before written (backlog A6, A7)

- **A6.** The spec says LV separation "grows roughly linearly". At the
  declared horizon (700 steps, about two orbits) it is flat: median
  ratio end/start sits in a 0.6–1.4 band; the linear phase drift only
  appears over ~20 orbits. The test asserts a two-sided bound
  `0.1 < ratio < 10`, not a slope.
- **A7.** LV's invariant crosses zero inside the training box, so
  "drift relative to the initial value" measures the normaliser's
  distance from zero, not the integrator. The gate normalises by the
  span of initial invariant values across all benchmark starts; the
  literal ratio is still reported (`conserved_rel_drift_max_vs_initial`)
  for transparency, never hidden.
