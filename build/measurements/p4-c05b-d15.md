# P4-C05b measurement — does the true world agree with its own climatology? (owner question D15, new D21)

**In plain words:** the judge's "does the model still look like the world?" test compares a model's
guesses with a reference table. A perfect model — one that always guesses the true state — would
score the same as the true world does against that table. So the true world's own score is the
best any model can do, and the pass mark (average standardised gap ≤ 1.0) has to sit comfortably
above it. This note records that score, with and without the random kicks the evaluation trials
carry, for each region of each world.

**Method.** 200 seeded starts × 1,000 null-action steps → 16 equal-population ranges of the
conserved quantity (the owner-ruled replacement for the single long run, backlog A36). Then 64
seeded starts per region, run for the task horizon (capped at 1,500 steps), unkicked and with the
benchmark's seeded kicks; at each step the range is *re-measured* from the true state. Score = mean
over trials, steps and quantities of |state − range mean| / range sd. Reproduce with the snippet
at the end. Seed 20260825. **These are build-time facts about the instrument, not about any model;
no model was involved.**

**Reading it.** In the training region the true world scores ≈ 0.84–0.89, so a perfect model passes

construction). In the kicked runs, 33–68% of (trial, step) cells (58–91% of trials at least once, see the correction) sit in a different range from step 1, so re-measuring
at each step matters. But in the two *state-axis out-of-range* regions the true world itself scores
above the pass mark (1.24; 4.8–5.3) because their states lie beyond what the training-region table
describes: **a perfect model would be told it "disagrees with the world".** In the pendulum's
`out-near-inverted` region — the only place the real tasks ever reach a switch step (step 4,750)
— the instrument is wrong by construction.

## What this means (owner decision D21, recorded in `REMEMBER.md`)
1. With the spec's single training-region table (A), the agreement test **cannot be passed by a
   perfect model** in the out-of-range regions. It must not be presented as a finding about a model.
2. Per-region tables (B) fix four of six regions; the remaining two (pendulum out-near-inverted,
   pendulum kicked out-large-action) still leave a perfect model at or above the pass mark.
3. The pass mark (1.0, `prereg/thresholds.json`) is pre-registered. It must not be changed after
   seeing results; this measurement is a build-time check of the instrument, taken *before* the freeze.
   Whether to move it (and the table recipe) is for the owner and the next design review, on the
   record, before the freeze.
4. Whatever is decided, the verdict should say plainly (JU-10) that the agreement test is judged
   against a reference the true world itself only approximately meets.

## Correction after independent review (2026-10-14): score the judge's window, and mind the run length

The tables above score every step from 1 to 1,500 (early time). The judge averages only from a task's
**switch step to its horizon**, and only when a switch step exists. On the real worlds that is exactly
one place: pendulum `out-near-inverted`, `dp-control`, steps 4,750–5,000. `truth_mean_abs_z` now takes a
`first_step` so the same window can be scored. Re-measured there (same 64 trials, seed 20260825, full
5,000-step horizon, `out-near-inverted` trials; "full" = steps 1–5,000, "window" = steps 4,750–5,000):

| reference table | starts × steps | truth score, unkicked (full / window) | truth score, kicked (full / window) |
|---|---|---|---|
| training region | 200 × 1,000 | 8.92 / 13.47 | 11.59 / 20.17 |
| training region | 200 × 5,000 | 9.08 / 13.80 | 11.80 / 20.66 |
| training region | 50 × 20,000 | 8.19 / 12.45 | 10.66 / 18.68 |
| that region's own starts | 200 × 1,000 (the spec-sized recipe) | 2.56 / **4.26** | 3.15 / **5.90** |
| that region's own starts | 200 × 5,000 | 0.83 / **0.98** | 0.96 / **1.26** |
| that region's own starts | 50 × 20,000 | 0.82 / **0.84** | 0.85 / **0.96** |

**Reading it.**
1. Result B's "≈ 1.0" for this region was an artefact of scoring only the first 1,500 steps and of the short
   reference run: 1,000 steps at dt = 0.002 is 2 time units against a 10-unit horizon in a chaotic region.
   In the judge's actual window a perfect model scores **4.3 (unkicked) / 5.9 (kicked)** against the
   pass mark of 1.0 with the spec-sized recipe.
2. The run length per start is the lever: with each region's own table built from **50 starts × 20,000
   steps** (five times the samples, 1,000,000, ≈ 5 s to build instead of ≈ 1 s) the window score falls to 0.84 unkicked / 0.96
   kicked — still passing, but with almost no margin when kicked.
3. Kicks are therefore *not* harmless for the pendulum once the long horizon is included (training
   region: kicked score 0.994 at 5,000 steps per start vs 0.833 unkicked; large-action kicked 2.65 with the
   training table, 3.10 with its own). The earlier statement "kicks do not upset the reference in the
   training region" holds for predator-prey and for the pendulum only at early times.
4. The "share of trials that change range" column counts (trial, step) cells differing from step 1; the
   share of trials that change range at least once is 58% / 84% / 86% / 91% for the four kicked rows with
   a moving range (the figures in the first table are lower bounds).

## Second correction (review pass 2): one table seed is not enough — the spread is larger than the margin

The same 64 `out-near-inverted` trials, the judge's window (steps 4,750–5,000), the region's own table
rebuilt with seven different run seeds (the note's seed 20260825 and 1–6):

| table recipe | unkicked, 7 table seeds | kicked, 7 table seeds |
|---|---|---|
| 200 × 1,000 (spec-sized) | 4.26 4.07 4.05 4.21 4.24 4.29 4.07 — all above 1.0 | 5.90 5.19 5.34 5.45 5.39 5.98 5.85 — all above 1.0 |
| 50 × 20,000 | 0.84 0.79 0.82 0.81 0.77 0.84 0.87 — all below 1.0 | 0.96 0.99 0.99 **1.27** 0.86 **1.13** **1.14** — 3 of 7 above 1.0 |

**Reading it.**
1. With the spec-sized recipe a perfect model fails the test every time, kicked or not.
2. With long runs a perfect model passes when unkicked (0.77–0.87) but, when kicked, scores anywhere
   from 0.86 to 1.27 depending only on which random starts built the table — so it fails the pass mark
   of 1.0 on about half the seeds. A longer reference run is **necessary but not sufficient**.
3. Beyond the one measured window: at the full 5,000-step horizon the pendulum's kicked scores are
   0.99 (training region) and 2.7–3.1 (`out-large-action`); the "0.8–0.9 elsewhere" figures hold only
   for horizons up to 1,500 steps or for predator-prey. Today those cells are not *scored* (no switch
   step), but that would change if a tolerance or horizon changed.
4. For the owner: the pass mark (mean standardised gap ≤ 1.0) sits where the true world's own score
   lies in the kicked chaotic case. Whatever is decided, the pass mark has to be set from the
   distribution of a **perfect model's** score (known now, before any model has been judged), with
   headroom above the worst of those, and recorded in `prereg/` before the freeze.
